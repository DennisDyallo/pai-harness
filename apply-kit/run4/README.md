## PART A — graduated-rules block (durable fix patches the GENERATOR)

The `GRADUATED_RULES_START/END` block in the global CLAUDE.md is auto-generated by
`~/.claude/hooks/handlers/ConsolidateLearnings.ts`. A plain CLAUDE.md edit would be
clobbered on the next consolidation run, so the fix patches the generator.

- `ConsolidateLearnings.ts.patch` — unified diff vs the live handler (applies cleanly).
- `ConsolidateLearnings.patched.ts` — full patched file (convenience).
- `test-generator.sh` — self-contained proof. Run:
  `bash test-generator.sh ConsolidateLearnings.patched.ts`

Patched behavior:
- **Reference file:** `<PAI_DIR>/MEMORY/graduated-rules.md` (default
  `~/.claude/MEMORY/graduated-rules.md`, matching existing `~/.claude/MEMORY/...`
  references in CLAUDE.md). Both the file path and the inline pointer text are
  derived from `PAI_DIR` so clones / alternate installs stay consistent.
- **CUMULATIVE ref (data-loss fix):** the consolidator only clusters *unconsolidated*
  index entries, so any single run sees only a partial batch. The patched generator
  therefore LOADS the existing rule set first — from the ref file, or (on the first
  run after this patch) MIGRATED from the rules already in the live CLAUDE.md block —
  MERGES the new batch into it (dedupe by title slug; on collision keep max
  incidents, max confidence, and the richer body), and writes the UNION. A small new
  batch can never wipe previously graduated rules. An empty batch leaves the existing
  ref + inline block untouched (no overwrite-with-nothing).
- **Inline block:** a one-line `read` pointer + the **top 5** rules chosen from the
  FULL cumulative set (`INLINE_RULE_LIMIT`), each shown as heading + metadata + the
  first 3 bullets (`INLINE_BULLET_TEASER`) with a "…and N more" marker.
- **Top-N ranking:** composite score `incidents*100 + confidence` — incident count
  dominates, but the confidence term prevents a very-high-confidence, lower-incident
  rule from being demoted off the always-on inline set (avoids needing a pin list).
- **Marker-safe writes:** both markers present → replace the block; neither → insert a
  fresh block before the PAI Skill System section; exactly one marker (malformed) →
  THROW and fail loudly. Never logs success on a silent no-op or leaves a stray marker.

`test-generator.sh` verifies all of: shape, idempotency, cumulative-merge (no prior
loss), first-run migration from the CLAUDE.md block, and the malformed-marker failure.

To apply (NOT done here). NOTE: `~/.claude` is a symlink, so `git apply` on it fails
("beyond a symbolic link"). Use GNU `patch -p1` from `$HOME`, or `git apply` against the
resolved vault path:
```
cd "$HOME" && patch -p1 < <kit>/ConsolidateLearnings.ts.patch   # or copy the patched file
bun ~/.claude/hooks/handlers/ConsolidateLearnings.ts           # regenerates block + cumulative ref
```
